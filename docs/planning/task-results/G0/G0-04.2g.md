## Frozen API

Package `sshlab`; `NewFixture() (*Fixture, error)` constructs ephemeral Ed25519
host/client keys and a loopback port-0 listener. `Endpoint() string`,
`HostKey() ssh.PublicKey`, `ClientSigner() ssh.Signer`,
`Stats() FixtureStats`, `Close() error`. `FixtureStats` has integer
`AuthCallbacks`, `ExecAttempts`, `Commands`. Stats returns a mutex-protected
snapshot. ExecAttempts counts rejected exec requests; Commands counts only
accepted `fixture.complete`, `fixture.block`, `fixture.large` requests.
Close is idempotent, closes owned sockets and the block wait channel, then joins
owned goroutines. No shell/PAM/systemuser/PTY/subsystem/forwarding/Keychain use.
