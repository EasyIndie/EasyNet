`(*Fixture).AuthReached() <-chan struct{}`. NewFixture remains compatible and

without holding the mutex. Close releases the stalled callback and joins all

probe after trusted SSH key exchange; it does not establish signed-auth success.

## Actual fault behavior

- An owned loopback listener accepts the real client, writes a valid SSH banner,
  and withholds key exchange. Reading and validating the actual client SSH-2.0 identification under the
  owned socket deadline establishes the partial-handshake fault; no sleep establishes state. A 100 ms context
  deadline produces a timeout error in under one second. Owned listener/socket
  and server worker are released/joined before final zero-auth/exec/command
  fixture counter assertion; cleanup is idempotent.
- An authentication-stall fixture completes SSH key exchange with supplied
  matching host trust and enters its real public-key callback. AuthReached is
  observed. A 100 ms context deadline produces a timeout error in under one
  second. Checked Close joins the stalled worker; final counter snapshot shows
  positive auth callbacks, zero exec attempts and zero accepted commands.
- Both tests require a timeout/deadline error via errors.Is or errors.As to
  net.Error.Timeout, and reject any successful returned client. The sub-second
  bounds are assertions, not inferred from the package's overall runtime.
