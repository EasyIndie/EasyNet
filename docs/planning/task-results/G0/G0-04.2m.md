## API and ownership

Added lab-only `Run(ctx context.Context, client *ssh.Client, operationID,
command string) (Result, error)`. Result carries OperationID, Outcome,
OwnerRetained and copied Output bytes. Run takes exclusive ownership of a
nonnull client even on input rejection; closes it and waits for its SSH
transport on every return. Session.Wait joins copy waiters after a successful
Start. A context.AfterFunc closes the owned client on cancellation; cleanup
stops or joins the callback. It is not a borrowed-client or production adapter.

Missing context/client, empty/>64/non-simple-ASCII operation IDs, unknown command
and pre-cancelled context reject before session creation or Start. An additional
context check before Start preserves pre-dispatch rejection. Immediately before
Start, outcome becomes unknown and ownership retained: Start errors may follow
remote acceptance, so they never certify not-dispatched. No retry is implemented.
Successful exit reports only fixture-complete-observed and keeps OwnerRetained
true; no production receipt or ownership release is claimed.

One boundedOutput-backed wrapper serves both stdout and stderr. A limit error
immediately closes the owned client to unblock readers. After joined session
wait, Overflowed takes precedence over socket-close/other errors and returns
fixed ErrOutputLimit. Retained Output is a copy capped at 4096 bytes.

Fixture.large now writes 4096 stdout + 4096 stderr bytes concurrently and joins
its local stream worker before completing; the fixture session worker owns that
child lifecycle. No additional tokens or external resources introduced.
Run source 85 lines + tests 85 + fixture delta 4 = 174 authored added lines.

## Actual behavior

- Matching real SSH fixture.complete returns exact fixed bytes and
  fixture-complete-observed with original operation ID and OwnerRetained=true.
- Fixture.large's combined output returns ErrOutputLimit, unknown and retained
  ownership with original ID. Output is exactly 4096 bytes. The server records
  exactly one exec attempt and accepted command after joined fixture cleanup,
  proving no replay. Client no longer permits new sessions after Run returns.
- Empty/long/unsafe ID, arbitrary command, nil context and pre-cancelled context
  return not-dispatched, no retained owner and no output. After joined fixture
  cleanup each has zero exec attempts/commands and an owned closed client.
  Nil client separately rejects before dispatch.
