The adapter stores one canonical strict JSON BLOB plus typed headers in a fixed
SQLite STRICT ANY table. ANY plus typeof checks avoids numeric affinity coercion;
exact schema/column/index/constraint/type checks precede projection and refs.
Native statements/handles/C buffers have explicit ownership, fixed SQL only,
no public native error/path/content. READONLY diagnosis runs before any commit RW
open; named-root/database identity checks and outer flock surround native access.
Transactional CAS uses BEGIN IMMEDIATE and conditional whole-row update. Shared
model validation preserves fixed error codes, zero snapshots and immutable mirrors.
Once COMMIT is invoked, uncertain outcomes are CommitUnknown with no replay.

Ordinary safe-journal presence refuses without recovery; corrupt/future diagnosis
never repairs or opens RW. Only killed-and-reaped owned-child provenance permits
harness recovery. It checks exact old/successor membership before any optional
no-op journal lifecycle transaction, then freezes the recovered physical baseline.
Failed hot/recovery/purity qualification preserves the fixture while reaping all
children and closing descriptors. Final cleanup validates the whole inventory,
including creator-recorded names, before any unlink; no recursive deletion.

trials and one early-exit child. All were Waited before fixture cleanup. The full
package additionally reran the existing JSON harness's 19 children; do not call

1 and8 respectively. No mixed records or extra increment. All ten before/boundary

page4096. Four after trials had no hot journal. The six boundary races happened

exclude a permitted completed-commit new snapshot without journal.

Harness recovery recorded physical changes on ten hot-journal trials and none
on four already-committed trials. Native recovery removed journals without manual
hot-journal deletion. Every recovered snapshot was compared in full, then three
v1 Load+Snapshot or v0 inspection repetitions preserved names/bytes/modes/generation.
Atime is excluded. This is controlled process-kill evidence, not power-loss testing.
