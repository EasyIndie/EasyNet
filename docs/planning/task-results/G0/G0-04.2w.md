# G0-04.2w — Go credential frame codec

Added the pure in-memory `EncodeBridgeFrame` codec for the frozen v1 layout. It validates fixed ranges, ASCII operation IDs, SSH Ed25519 public blobs, and unencrypted OpenSSH PEM Ed25519 private keys; PKCS#8, PEM headers, and non-whitespace trailing data are rejected. It returns fixed errors with nil frame and copies all encoded payload bytes.

`TestBridgeFrame` validates big-endian header/payload bytes, memory-copy behavior, 64/65 ID boundary, invalid ports/deadlines/commands/IDs, malformed, oversized, and non-Ed25519 host keys; malformed, oversized, invalid-UTF8, and PKCS#8 private keys; and nil fields. Test keys are generated and marshaled in memory; no key data is logged.
