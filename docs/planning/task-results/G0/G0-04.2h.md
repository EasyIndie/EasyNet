## Implementation

Added client.go (72 lines) and client_test.go (100 lines); 172 authored gofmt
lines. Frozen API: `Dial(ctx context.Context, endpoint string, expected
ssh.PublicKey, signer ssh.Signer) (*ssh.Client, error)` and sentinel errors
`ErrUnknownHost`, `ErrChangedHost`. Nil expected trust refuses before any socket
connection; a nonmatching observed key returns ErrChangedHost through SSH's
wrapped error. Supplied expected bytes are copied and compared before auth,
without enrollment/mutation. No agent APIs or forwarding.

The endpoint must contain a literal loopback IP and a decimal port 1–65535;
DNS names, nonloopback IPs, malformed ports and missing signer are refused.
User is always synthetic `fixture`. Already-cancelled contexts refuse before
connection. Owned raw net.Conn gets an absolute deadline before SSH handshake:
minimum of caller deadline and current time + three seconds. This deadline stays
on the connection for session/output. Every handshake/setup error closes the
owned socket; successful client lifecycle belongs to the caller.

## Actual behavior

- Matching independent supplied host key completes real SSH signed-key auth;
  `fixture.complete` returns exact `fixture complete\n`. Auth callback is
  positive; one exec attempt and one accepted command. Supplied trust unchanged.
- Unknown trust and changed host key return their distinct sentinel errors;
  zero fixture auth callbacks, exec attempts and commands. Changed supplied
  trust bytes remain unchanged. Unknown trust performs no enrollment.
- Wrong generated signer fails authentication; positive auth callback,
  zero exec attempts and commands; supplied matching trust unchanged.
- Malformed endpoint, DNS hostname, nonloopback documentation IP, zero/out-of-
  range/signed ports, nil signer and already-cancelled context fail without
  fixture auth/exec/commands. Only fixture-owned loopback sockets were used.
