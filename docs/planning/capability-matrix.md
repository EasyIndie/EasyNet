# Capability matrix v1: current code evidence

Frozen v1: 2026-10-06, following G0-02.3 review of the corrected G0-02.2 fixtures. This is a bounded source/fixture inventory, not a live support statement. “Code eligibility” describes branches and inputs accepted by the inspected code; “fixture evidence” distinguishes executed isolated tests from inspected test definitions; “live support” is `unknown` unless a matching target acceptance result exists. No matching live OS/VPS acceptance evidence was supplied for this inventory. This matrix makes no controller language or runtime selection.
