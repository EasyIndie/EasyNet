## 下一批必须先冻结的条件

下一张是 [G0-04.2a：候选 A SSH PoC](task-cards/G0/G0-04.2a.md)，仍 locked。
准备者需基于三份证据经审查登记 A/B 候选理由，仅用于比较，不是生产语言选择。
为每个候选固定可用工具链、依赖版本、精确实现文件和可执行验收命令，
再解锁分配给 Sol medium。当前缺少 Rust 工具链，已有 Go 也不能证明调研版本可构建；
不得因本地编译器可用就免除依赖核对，或用假实现冒充 SSH 库验证。

SSH 试验使用一次性、非 root 的本地 loopback fixture、临时密钥和独立 trust/config，
不读取真实凭据、不转发 agent、不改系统 SSH 服务。两候选必须覆盖同样的 key auth、
未知/变化主机密钥在认证前拒绝、连接/认证/命令期限、输出限制以及分派前后取消。
分派后连接中断保留 unknown 和操作归属，不能用本地进程退出证明远程结果。
具体 fixture 必须先确认能在目标环境安全运行；缺少工具链/fixture/命令时继续保持 locked。
真实 vault 行为留在独立 vault 卡，result/打包留在各自卡；最终由 G0-04.3 比较并接受 ADR-004。

演进继续保留在同一 feature 分支；全部 G0–G6 和最终验收完成后才提出单次 main 合并。
